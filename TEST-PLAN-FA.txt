AURALIS v0.10.5 — AUDIO PATH HARDENING TEST PLAN
================================================

هدف اصلی این نسخه:
اثبات مسیر Mic -> PCM Decode -> VAD -> Segment -> ASR -> Live Transcript و بررسی کاهش لگ شروع Session/Capture.

پیش‌نیاز:
- برای تست اول فقط Mic روشن باشد.
- System Loopback خاموش.
- در Brain کلید Gemini را وارد و «فعال‌سازی صوت→متن + Brain» را بزن.

TEST 1 — FORMAT / LEVEL
Session و Native Capture را روشن کن و 5 ثانیه حرف بزن.
PASS:
- user-mic seq افزایش یابد.
- Encoding باید یکی از float32/float64/pcm16/pcm24/pcm32 باشد.
- هنگام حرف زدن RMS از threshold بالاتر رود و voice=YES دیده شود.
FAIL BLOCKER:
- DECODE_FAILED یا encoding ناشناخته.
- seq بالا برود ولی RMS همیشه صفر باشد.

TEST 2 — MIC TO TEXT
بگو: «واریانس در مدل رگرسیون چیست؟» سپس 1 تا 2 ثانیه سکوت.
PASS:
- Segment ساخته شود.
- Live Transcript متن نهایی را نشان دهد.
- Turn Card مستقل ایجاد شود.

TEST 3 — TURN SEPARATION
با مکث حدود 1.5 ثانیه سه سؤال بگو:
1) واریانس چیست؟
2) ضریب تعیین چیست؟
3) رگرسیون از مبدأ چه زمانی مناسب است؟
PASS:
- 3 Segment مستقل.
- 3 Transcript مستقل.
- 3 Turn Card مستقل.
- انتخاب هر کارت سؤال و پاسخ همان Turn را نشان دهد.

TEST 4 — SILENCE
30 ثانیه سکوت.
PASS:
- Turn خیالی ساخته نشود.
- متن ساختگی ظاهر نشود.

TEST 5 — STARTUP RESPONSIVENESS
شروع Session و سپس شروع Native Capture را بزن.
در summary دو عدد session-start و capture-start ثبت می‌شوند.
این عددها را Screenshot بگیر. هدف این validation این است که UI قفل نشود و درخواست‌ها overlap نکنند؛ عدد نهایی release gate بعد از تست روی چند Windows تعیین می‌شود.

TEST 6 — SYSTEM LOOPBACK
پس از پاس شدن Mic:
Mic OFF، System Loopback ON، یک صدای فارسی پخش کن.
PASS:
- system-loopback seq افزایش یابد.
- encoding/RMS قابل مشاهده باشد.
- Transcript با source_role=system ساخته شود.

TEST 7 — GAPS
Diagnostics را بررسی کن.
هر gap باید reason روشن داشته باشد. gap پنهان مجاز نیست.

TEST 8 — 20 MINUTE
فقط اگر TEST 1 تا 7 پاس شد.
20 دقیقه capture و گفتار دوره‌ای.
PASS اولیه:
- برنامه responsive بماند.
- transcript/turn association خراب نشود.
- memory یا queue بدون کنترل رشد نکند.

فعلاً 60/120 دقیقه Release Gate نهایی محسوب می‌شوند و باید بعد از پایدار شدن این مسیر انجام شوند.
