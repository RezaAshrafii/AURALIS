Auralis v0.10.4 source snapshot

- The package contains the Go source for the Windows WASAPI validation probe and the compiled validation executables used by the matching Portable artifact.
- runtime/bun.exe is not included in the Source snapshot; it is bundled only in the Portable artifact.
- Validation probes can be rebuilt with scripts/build-validation-probes.ps1 when Go is installed.
- The target production Rust core remains under native/core and is not claimed as compiled here because rustc/cargo are unavailable on the artifact host.
- Use the Windows Portable package for immediate audio-to-text testing.
