Auralis v0.10.5 source snapshot

Primary delta over v0.10.4:
- byte-accurate WAVEFORMATEXTENSIBLE parser
- cross-platform Go unit tests for audio format detection/downmix
- VAD decode-failure and live level telemetry
- reduced UI polling/render work and completed-ledger startup replay
- background native-probe prewarm

The Windows validation probe is cross-built from native-probe with Go 1.23 in this build environment. The final v0.10 production requirement remains a Rust stable/windows-rs core; that claim is intentionally not made here.
