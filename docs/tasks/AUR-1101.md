# AUR-1101: Reproducible source foundation

## Status

Implemented and verified on `dev/AUR-1101-foundation` from baseline commit `28f7092`.

## Objective

Establish deterministic local verification and repository hygiene for the AURALIS source workspace without changing runtime, API, native, or UI behavior.

## Baseline discrepancy

The Windows checkout originally reported one UI regression failure because `app/styles.css` contained CRLF while a test searched for an LF-only multiline string. The expected CSS rule was present. The approved fix normalizes CRLF to LF in test memory before retaining the existing assertion; application CSS is unchanged.

## Scope

- Define deterministic LF handling for tracked text.
- Ignore local runtime state, generated/binary media, databases, secrets, caches, and build output.
- Provide dependency-free `test` and `verify` npm scripts.
- Add a deterministic validation entry point, architecture boundary document, one migration ADR, and a machine-readable handoff.
- Make only the approved line-ending portability adjustment in the existing test suite.

## Allowed paths

- `.gitignore`
- `.gitattributes`
- `package.json`
- `CLAUDE.md`
- `scripts/verify.mjs`
- `docs/architecture.md`
- `docs/adr/**`
- `docs/tasks/AUR-1101.md`
- `handoff/AUR-1101.json`
- `tests/v01010-ui-regression.test.mjs`, only for CRLF/LF normalization in memory

## Excluded paths and behavior

Do not change `server.mjs`, `core/**`, `app/**`, `native/**`, runtime/data/release dependency trees, binary fixtures, executables, API contracts, or application behavior.

## Acceptance criteria

1. `node --test "tests/*.test.mjs"` completes with zero failures.
2. `npm test` completes with zero failures.
3. `npm run verify` completes successfully without external dependencies.
4. `git diff --check` reports no whitespace errors.
5. Native/probe skips caused by absent generated or unshipped artifacts are explicitly reported.
6. Only approved paths change, with no binary, runtime artifact, database, captured audio, or secret introduced.
7. Current architecture and target direction remain visibly distinct.
8. Exactly one ADR records the incremental migration decision.
9. The implementation is committed once with the approved commit message and is not pushed, tagged, or released.

## Verification commands

```text
node --test "tests/*.test.mjs"
npm test

```
