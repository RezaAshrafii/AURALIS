# AUR-1103 — Incremental TypeScript + Vite Foundation

## Objective

Add a deterministic React 18, TypeScript, and Vite frontend build around the existing v0.10.12 UI without redesigning it or changing the CURRENT `/v1` contract.

## Implementation boundary

- `apps/web/` is the new typed build workspace.
- The TypeScript entry establishes a typed React/ReactDOM bridge and imports the existing `app/ui-kit.js`, `app/app-react.js`, Bootstrap CSS, and product CSS directly.
- `app/` remains the current Bun-served source path and runnable fallback during incremental migration.
- `AURALIS_USE_VITE_BUILD=1` selects the generated Vite artifact for smoke testing; `AURALIS_NO_BROWSER=1` prevents the service from opening an external browser during automation. Defaults are unchanged.
- No UI source is copied into the Vite workspace; visual and behavioral changes remain out of scope.
- No WebSocket, SSE, endpoint, or event is added by this task.

## Dependency policy

Only React 18, ReactDOM 18, TypeScript, Vite, and their React type declarations are introduced. All direct versions are exact and the npm lockfile is authoritative. No test framework, CSS framework replacement, router, state library, or Vite React plugin is added.

## Acceptance criteria

1. Existing regression and CURRENT contract tests pass without endpoint or event drift.
2. `npm run frontend:typecheck` passes with strict TypeScript settings.
3. `npm run frontend:test` passes using the repository's Node test runner.
4. `npm run frontend:build` produces `dist/web/` successfully from pinned dependencies.
5. The Vite entry reuses the existing UI components and styles; no aesthetic redesign occurs.
6. The existing `app/` UI remains runnable through `server.mjs`.
7. `npm run verify` includes the frontend gates and passes.
8. No generated build output, runtime data, binary, database, captured audio, or credential is committed.

## Verification

```text
npm run frontend:typecheck
npm run frontend:test
npm run frontend:build
node --test "tests/*.test.mjs"
npm run verify
git diff --check
```
