# AUR-1201 — Audio Core Domain and Persistence

## Objective

Turn the Rust scaffold into a tested production-domain and SQLite WAL foundation for sessions, channels, chunks, gaps, capture/device/recovery state, and per-channel native audio metadata.

## Acceptance criteria

1. Rust 1.97 compiles the workspace from the committed `native/Cargo.lock`.
2. Session, AudioChannel, AudioChunk, Gap, CaptureState, DeviceState, RecoveryState, and lifecycle transition entities are explicit and serializable.
3. Frame/channel/chunk metadata represents source kind, sample rate, channel count/mask, sample format, monotonic sequence, QPC range, and device position where available.
4. SQLite migrations enable foreign keys, WAL for file databases, schema versioning, lifecycle history, and sequence indexes.
5. Ledger writes validate formats/ranges and reject sequence regression transactionally.
6. Gaps are durable entities; no persistence API represents loss as an unreported drop.
7. Rust fmt, clippy, unit/integration tests, JavaScript regressions, and repository verification pass.
8. No generated binary, target output, runtime database, audio, or credential is committed.

## Verification

```text
cargo fmt --manifest-path native/Cargo.toml --all -- --check
cargo clippy --manifest-path native/Cargo.toml --workspace --all-targets --locked -- -D warnings
cargo test --manifest-path native/Cargo.toml --workspace --locked
node --test "tests/*.test.mjs"
npm run verify
git diff --check
```

## Completion evidence

- UNIT: Rust domain, state-transition, frame-validation, and persistence tests pass.
- INTEGRATION: file-backed SQLite opens in WAL mode and migrations are idempotent across reopen.
- FIXTURE: sequence regression, unexplained forward jumps, known gaps, and unknown gap extents are deterministic and queryable.
- INTEGRATION: repository verification runs Rust format/clippy/tests before frontend and existing regressions.
- REAL_WINDOWS_HARDWARE: not applicable to AUR-1201 and not claimed; capture validation begins with AUR-1202 and remains gated by AUR-1206.
