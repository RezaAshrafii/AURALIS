# AUR-1104 — Source Layout and v0.11 Gate

## Objective

Close the v0.11 Engineering Foundation milestone with synchronized version metadata, a deterministic frontend artifact build, an exact Windows smoke procedure, complete regression evidence, and a compact milestone handoff.

## Layout decision

The current layout already has meaningful `apps/`, `packages/`, `tests/`, `docs/`, and `scripts/` boundaries. `native/core/` remains the Cargo workspace member until production Rust implementation gives a functional reason to move it. A cosmetic repository-wide rename is out of scope.

## Acceptance criteria

1. Source version metadata is synchronized at `0.11.0`.
2. CURRENT routes/events/transport remain unchanged except version metadata.
3. `npm ci --ignore-scripts` can restore the exact pinned dependency graph.
4. `npm run build:v0.11:test` performs strict typecheck, frontend tests, two byte-identical Vite builds, and the complete regression suite.
5. Generated `dist/web/` is runnable through the existing loopback-only service using `scripts/run-v011-test.ps1` and a trusted external Bun runtime.
6. The exact build, launch, manual checklist, expected result, and failure evidence are documented.
7. `npm run verify` and `git diff --check` pass.
8. No binary, release archive, runtime database, audio, dependency tree, credential, or generated artifact is committed.
9. The v0.11 handoff reports real-hardware validation as pending rather than passing it via fixtures.

## Verification

```text
node --test "tests/v011-gate.test.mjs"
npm run build:v0.11:test
npm run verify
git diff --check
```
