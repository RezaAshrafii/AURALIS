# Auralis v0.10.12

## Focused Workspace & Conversation Hub

- Removed Processing Cycle from the main Session workspace; it remains in System diagnostics.
- Replaced raw Recent Sessions cards with a top-corner Sessions drawer.
- Added a minimal horizontal Current Session strip.
- Redesigned Live Transcript as a newest-first transcription-only feed with no horizontal scrolling.
- Added full Transcript Archive modal.
- Removed duplicated Q&A list from the main workspace.
- Added Conversation Hub modal for all turns and answer readiness.
- Selecting a turn displays its existing answer; it does not regenerate it.
- Preserved automatic background answer generation and Z hotkey override.
- Preserved source grounding, citations, audio capture, ASR and turn ownership behavior.
